# 每日天气 (Daily Weather)

![logo](logo.png)

一个 [AstrBot](https://github.com/Soulter/AstrBot) 插件：**每天定时推送天气预报**。
支持**和风天气**与免密钥的 **Open-Meteo** 两个数据源，每个会话可以订阅自己的城市。

## 功能

- **定时推送**：配置里写几个时刻（默认 `07:00` 与 `21:00`）。时刻早于 `evening_after`
  （默认 18 点）的推**今天**，晚于的推**明天**——所以默认就是"早上看今天、晚上看明天"
- **城市跟着人走**：`/天气 城市 上海` 设的是**你自己的**城市——同一个群里大家来自不同城市，
  各设各的、互不影响
- **天气卡片**：推送和 `/天气` 查询都会画一张 PNG 卡片（Pillow 本地绘制，
  **不需要开 AstrBot 的 t2i、也不联网**）；画不出来时自动退回纯文字
- **群推送支持多个城市**：管理员用 `/天气 订阅 上海 北京` 一次订阅多个城市，
  推送里**每个城市一段**（默认一条最多列 3 个，可配 `max_push_cities`）；
  也可以用 `/天气 添加城市`、`/天气 移除城市` 增量维护
- **两种数据源，自动选择**：
  - **和风天气**：填了 API Key 就用它，中文数据更全，能拿到**气象预警**
  - **Open-Meteo**：不用任何 Key，开箱即用（没有预警/空气质量/生活指数）
  - 和风取数失败会**自动回落到 Open-Meteo** 并记日志，不会因此不推
- **只在值得提醒时推**（`alert_only`）：打开后只有出现下列情况才推，其余日子静默
  - 有雨带伞（降水概率 ≥ 阈值；和风 3 天预报只有降水量，那时按"有降水量"提醒）
  - 降温加衣（下一天最高温比当前这天低 ≥ 阈值）
  - 大风、高温、严寒、强紫外线、昼夜温差大
  - **气象预警**（和风数据源；有预警一定会推）
- **不重复推**：`push_state.json` 按（日期 + 时刻）抢名额，**重载插件、甚至同时活着两个实例
  也只会推一次**；调度器登记表挂在框架 context 上，加载时先关掉残留调度器
- **失败不打扰**：接口超时/报错就不推这一条（并记日志），不会发半截消息
- 取数结果缓存（默认 30 分钟），多个目标同城市不会重复请求

## 安装

把插件目录放到 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理页启用：

```
astrbot_plugin_daily_weather
```

## 使用

**谁都可以用**（不需要管理员）：

```
/天气 [城市]        # 立即查天气（不填城市就用你自己的城市）
/天气 明天 [城市]    # 看明天的（也可以 今天 / 后天）
/天气 9月28日 [城市] # 看指定日期（也认 9-28 / 9/28 / 28号；接口只给未来 3 天）
/天气 城市 <城市>    # 设**你自己**的城市
/天气 帮助          # 显示帮助
```

日期词和城市可以随便换位置：`/天气 明天 北京`、`/天气 北京 后天`、`/天气 10月28日 上海` 都行。
超出 3 天会直接告诉你「只能查到这三天」，并列出具体日期，不会拿错的那天糊弄你。

**仅管理员可用**（会改全局推送目标、或可能打扰别的会话）：

```
/天气 订阅 [城市…]   # 订阅每日推送；可写多个城市：/天气 订阅 上海 北京
/天气 添加城市 <城市…> # 往本会话的推送城市里加
/天气 移除城市 <城市…> # 从本会话的推送城市里去掉
/天气 退订          # 取消订阅
/天气 订阅列表       # 查看订阅了哪些会话
/天气 测试 [全部]    # 立刻推一条试试（默认只发当前会话）
```

> **城市按人记，不按会话记**：一个群里几十号人来自不同城市，所以 `/天气 城市 北京` 只改你自己的；
> 群里任何人设城市都不会影响别人。想查一次临时城市、不动设置，就直接 `/天气 北京`。
>
> 群里**定时推送可以是多个城市**：管理员用 `/天气 订阅 上海 北京 广州` 设好列表，
> 推送里每个城市单独一段（一条最多列 `max_push_cities` 个，默认 3）。私聊订阅则用你自己的城市。
>
> 手动查询给非管理员加了轻量冷却（`query_cooldown_seconds`，默认 10 秒，**按人计**，
> 不会出现"别人查过我就不能查"）；管理员不受限。

推送长这样：

```
【今日天气 · 上海】2026-10-12 周一
☀️ 晴　现在 20.0℃（体感 21.3℃）　湿度 81%
气温 17~26℃　降水概率 4%　风 2 级（10km/h）
日出 05:54　日落 17:26　紫外线 5（中等）
· 今天昼夜温差 9℃，早晚加件外套
```

## 配置

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `provider` | 数据源：`auto`（有 key 用和风，否则 Open-Meteo）/ `qweather` / `openmeteo` | `auto` |
| `qweather_key` | 和风天气 API Key（留空则用免密钥的 Open-Meteo） | 空 |
| `qweather_host` | 和风专属 API Host，形如 `abcdefg.re.qweatherapi.com`（新版账号必填） | 空 |
| **`push_times`** | 推送时刻列表，每个时刻一条推送 | `["07:00", "21:00"]` |
| `evening_after` | 几点之后算"晚上"（推送改为看明天） | `18` |
| **`alert_only`** | 只在值得提醒时才推（有雨/降温/大风/高温/严寒/紫外线/预警） | `false` |
| `default_city` | 会话没单独设城市时用的城市 | 空 |
| `target_sessions` | 推送目标（由 `/天气 订阅` 维护，一般不用手填） | 空 |
| `at_all` | 群推送时是否 @全体成员 | `false` |
| `alert_rain_prob` | 提醒带伞的降水概率阈值（%） | `40` |
| `alert_temp_drop` | 降温提醒阈值（℃） | `5` |
| `alert_wind_kmh` | 大风提醒阈值（km/h） | `39` |
| `alert_heat` / `alert_cold` | 高温 / 严寒提醒阈值（℃），填 0 可关闭 | `35` / `0` |
| `alert_uv` | 紫外线提醒阈值，填 0 关闭 | `8` |
| `max_push_cities` | 一条推送里最多列几个城市 | `3` |
| `card_enabled` | 推送/查询时发天气卡片图片（失败自动退回文字） | `true` |
| `card_with_text` | 发卡片的同时再发一条文字（兜底用） | `false` |
| `card_width` | 卡片宽度（像素，手机上看 700~800 合适） | `760` |
| `query_cooldown_seconds` | 手动查询冷却（秒，非管理员；填 0 关闭） | `10` |
| `cache_minutes` | 取数缓存分钟数 | `30` |
| `timeout` | 天气接口超时（秒） | `15` |
| `footer` | 推送末尾附加的一行（可选） | 空 |

## 常见问题

- **问：到了时间没收到推送？**
  - 先发 `/天气 测试` 看看能不能出内容。收不到通常是两件事：① 这个会话没订阅
    （`/天气 订阅 上海`）；② 没设城市（会话没设、配置里 `default_city` 也空）——这两种情况
    插件会记日志跳过。另外 `alert_only=true` 时，平平无奇的日子本来就不推。
- **问：必须申请 API Key 吗？**
  - 不必。不填 Key 就用 Open-Meteo，开箱即用。想要**气象预警**、更全的中文描述和空气质量，
    再去 [console.qweather.com](https://console.qweather.com) 申请免费 Key（并把控制台里的
    专属 API Host 填进 `qweather_host`）。
- **问：为什么和风 3 天预报没有"降水概率"？**
  - 和风的日预报给的是**降水量**（mm），逐小时接口才有概率。所以用和风时"带伞提醒"
    按降水量判断；Open-Meteo 有概率字段，按概率判断。
- **问：卡片是用 AstrBot 的 t2i 渲染的吗？**
  - 不是。本插件用 **Pillow 本地绘制**（宽 760 的竖版卡片、按天气配色），
    所以**不需要开启 t2i、也不需要模板/远端端点**；中文用系统里的微软雅黑，
    emoji 用系统彩色 emoji 字体，缺字体时会自动跳过 emoji 而不报错。
    任何绘制异常都会退回纯文字，不会因此发不出天气。
- **问：一天想推三条行吗？**
  - 行。`push_times` 是列表，写 `["07:00", "12:00", "21:00"]` 就是三条（各自去重、互不影响）。
- **问：一个群里大家城市不一样，怎么设？**
  - 各设各的：`/天气 城市 北京`、`/天气 城市 广州`……都是**按人**记的，互不覆盖。
    之后每个人发 `/天气` 看到的就是自己的城市。要临时查别的城市就直接 `/天气 上海`。
    群里定时推送的城市由管理员用 `/天气 订阅 <城市>` 指定（群推送只能是一个城市）。
- **问：一个群的推送能同时报几个城市吗？**
  - 能。管理员发 `/天气 订阅 上海 北京 广州` 即可，推送里每个城市一段。
    默认一条最多列 3 个（`max_push_cities` 可调）；超出的会附一句提示，不会静默丢掉。
    开了 `alert_only` 时，**只有确实有值得提醒之事的城市**才会出现在那条推送里。
- **问：为什么推送的城市和我个人设的不一样？**
  - 群里推送用的是"这个群的推送城市"（管理员用 `/天气 订阅` 设的列表），
    不是某个成员的个人城市。想让推送按你的城市来，就在私聊里 `/天气 订阅 <城市>`。
